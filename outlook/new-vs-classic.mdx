Microsoft currently ships two Outlooks for Windows, and plenty of agencies run a mix. Lanten supports both — plus the web and Mac versions — but knowing which one you're in makes every other help page easier to follow.

## Which Outlook am I running?

The 10-second test on Windows: look at the top of the window.

- A **"New Outlook" toggle** in the top-right corner (or a left icon rail down the edge) → you're in **new Outlook**.
- A **File menu** in the top-left and the classic ribbon → you're in **classic Outlook**.

## Support matrix

| Outlook | Supported | Where Lanten appears |
| --- | --- | --- |
| New Outlook (Windows) | ✅ | **Apps** on the message, or the Lanten icon in the reading pane |
| Classic Outlook (Windows) | ✅ | The ribbon, and **Get Add-ins** for install |
| Outlook on the web | ✅ | **Apps** on the message |
| Outlook for Mac | ✅ | The toolbar on an open message |
| Outlook mobile (iOS/Android) | Not yet | See [Using Lanten on mobile](/outlook/mobile) |

## Does it matter which I use?

Lanten behaves the same in all four. The differences are Outlook's, not Lanten's — where the Apps button sits, how pinning looks, and how you customise the reading pane. Where steps differ, help pages here show tabs per client — see [Pinning Lanten](/getting-started/pin-lanten) and [Customising reading-pane actions](/outlook/reading-pane-actions).

<Tip>
  If you've just switched the New Outlook toggle and Lanten seems to have vanished, it hasn't — it's installed to your mailbox, not the app. Open any email → **Apps** → Lanten, then [pin it](/getting-started/pin-lanten) again.
</Tip>
